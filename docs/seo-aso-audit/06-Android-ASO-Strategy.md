## 6. Key Differences: Play Store vs. App Store ASO

| Factor | Google Play | App Store |
|--------|-------------|-----------|
| **Description indexed?** | ✅ Full description indexed for search | ❌ Description NOT indexed — only Name, Subtitle, Keywords field |
| **Keyword strategy** | Embed keywords naturally in description (3–5x per term) | Keyword field is the only lever (100 chars, no spaces) |
| **Algorithm signals** | Install velocity, uninstall rate, engagement, ANR/crash rate | Downloads, ratings, engagement |
| **Rating signals** | Rating velocity and recency weighted heavily | Average score + volume |
| **Retention** | Day-1, Day-7, Day-30 retention are ranking signals | Less direct, but engagement matters |
| **A/B testing** | Store Listing Experiments (native) | Product Page Optimization |
| **Segmentation** | Custom Store Listings per audience, country, UTM source | Product Pages (linked externally) |
| **Seasonal features** | LiveOps Cards (similar to In-App Events) | In-App Events |

## 8. Rating and Review Strategy

### When to Prompt
Same trigger as iOS: **after the Match celebration screen**. On Android, use the **Google Play In-App Review API** (`expo-store-review` handles both platforms).

```typescript
import * as StoreReview from 'expo-store-review';

// After match animation completes (~1.5s delay)
const promptReview = async () => {
  const isAvailable = await StoreReview.isAvailableAsync();
  if (isAvailable) {
    await new Promise(r => setTimeout(r, 1500));
    await StoreReview.requestReview();
  }
};
```

**Play-specific rules:**
- Google Play In-App Review API has a **quota per user** (not documented, ~2–3x per 30 days)
- The review sheet appears in-app — user never leaves the app
- Do NOT redirect users to the Play Store listing to rate — policy violation

### Review Velocity Signals
Play Store weights **recent reviews** more than historic average. A burst of 1-star reviews in a week can tank ranking even if the historical average is 4.8.

**Monitor daily** for the first 30 days via Play Console → Ratings → Ratings over time.

### Responding to Reviews
Play Console allows replies. Android users who receive a reply are notified — reply to 1-star and 2-star reviews within 48 hours. Updated reviews (user edits their rating after your reply) are a positive signal.

## 9. Install Velocity and Retention

Play Store's algorithm weights these more heavily than App Store:

**Install velocity:** Launch with a small coordinated group (personal network, beta testers) to create early momentum. Aim for 50+ installs in the first 48 hours.

**Uninstall rate:** Apps with high early uninstall rates (first 24 hours) are deprioritised. Ensure onboarding is smooth — the first-time user must understand the propose → vote → match flow without friction.

**Android Vitals:** Play Console monitors crash rate and ANR (App Not Responding) rate. Apps above threshold lose Store ranking visibility. Target: crash rate < 1%, ANR rate < 0.47%.
