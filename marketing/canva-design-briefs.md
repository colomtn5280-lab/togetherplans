# DateNight — Canva Design Briefs
> Exact specifications for 5 design templates. All designs use DateNight brand colors and Canva-available fonts.

**Brand Colors:**
- Primary Purple: `#7c3aed`
- Dark Purple: `#5b21b6`
- Deep Purple BG: `#3b0764`
- Pink Accent: `#FF4081`
- White: `#FFFFFF`
- Light Purple (tints): `#ddd6fe`, `#ede9fe`
- Text Gray: `#f3f4f6`

**Brand Fonts (all available in Canva):**
- Headlines: **Montserrat ExtraBold** or **Raleway Bold**
- Body/Subheads: **Montserrat Regular** or **Inter**
- Accent/Display: **Playfair Display** (for romantic tone variants)

## Template 1: Instagram Post — 1080×1080px (Two Variants)

### Canvas Setup
- Size: **1080 × 1080 px**
- Resolution: 72 DPI (screen)
- File format: PNG or JPG

---

### Variant A — Relatable Humor Post

**Concept:** Meme-style text post. Relatable couple frustration that ends with the app as the punchline/solution.

#### Layout (top to bottom):
1. **Background:** Full-canvas solid color `#3b0764` (deep purple)
2. **Subtle texture overlay:** Add a dark gradient overlay from `#5b21b6` at top (20% opacity) fading to transparent at center
3. **Top label (y: 120px):** Small pill/badge shape — `#FF4081` fill, white text
   - Font: Montserrat Bold, 28px
   - Text: `EVERY. SINGLE. WEEKEND.`
   - Width: ~480px, centered
4. **Main headline block (y: 220–520px):** Two-part meme text, centered
   - Line 1: Font: Montserrat ExtraBold, **80px**, white
     - Text: `"What do you want`
   - Line 2: Font: Montserrat ExtraBold, **80px**, white
     - Text: `to do tonight?"`
   - Line 3: Font: Montserrat ExtraBold, **80px**, color `#ddd6fe` (light purple)
     - Text: `"Idk, you pick."`
   - Add 24px gap between lines 2 and 3
5. **Divider line (y: 560px):** Horizontal rule, `rgba(255,255,255,0.15)`, 600px wide, centered
6. **Resolution line (y: 610–660px):**
   - Emoji + text: `📅 DateNight ends this loop.`
   - Font: Montserrat SemiBold, 38px, color `#FF4081`
   - Centered
7. **CTA (y: 720px):**
   - Text: `togetherplans.app — free`
   - Font: Montserrat Regular, 30px, color `rgba(255,255,255,0.65)`
   - Centered
8. **Logo/wordmark (bottom-right, y: 980px x: 880px):**
   - Small "@togetherplans" in white, 22px, Montserrat Regular
   - Low opacity (60%)

**Color palette for this variant:**
- Background: `#3b0764`
- Headline: `#FFFFFF`
- Secondary text: `#ddd6fe`
- Accent badge: `#FF4081`
- CTA text: `rgba(255,255,255,0.65)`

### Variant B — Feature Highlight Post

**Concept:** Clean, product-forward design. Shows the app flow (propose → vote → go) as a visual benefit list.

#### Layout:

2. **Decorative element (top-right):** Semi-transparent circle

   - Position: x: 840px, y: -80px
   - Fill: `rgba(255,255,255,0.05)`

   - Text: `HOW IT WORKS`

   - Centered
4. **Main headline (y: 200–280px):**

   - Centered
5. **Three feature rows (y: 340–620px):** Each row is an icon + text line

## Template 4: Physical Flyer — 8.5×11 inches (Coffee Shop / Campus)

### Canvas Setup
- Size: **8.5 × 11 inches** (Canva → Custom size → 8.5in × 11in)
- Resolution: **300 DPI** (File → Download → PDF Print or PNG at 300 DPI)
- Bleed: Add 0.125" bleed on all sides if printing professionally

### Layout (top to bottom — portrait):

1. **Background:**
   - Full-page gradient: `#3b0764` top → `#7c3aed` center → `#5b21b6` bottom
   - OR: white background with purple header block for ink-friendly printing

2. **Header block (top 2.5 inches):**
   - Fill: `#7c3aed`
   - App name: `DateNight`
     - Font: Montserrat ExtraBold, **72pt**, white
     - Centered, y: ~1 inch from top
   - Tagline: `Plan Together. Go Together.`
     - Font: Montserrat Light, **28pt**, `#ddd6fe`
     - Centered, y: ~1.9 inches from top

3. **Problem headline (y: 3.2 inches):**
   - Text: `Tired of "idk, what do you want to do?"`
   - Font: Raleway Bold, **36pt**, `#3b0764` (on white variant) or white (on dark)
   - Centered

4. **Three-step visual (y: 4–6.5 inches):**
   - Three horizontal columns, each ~2.5in wide
   - Each column: Large emoji (emoji element, ~64pt) + step title + short description

   | Step | Emoji | Title | Description |
   |------|-------|-------|-------------|
   | 1 | 💡 | Propose | Each person suggests date ideas |
   | 2 | 🗳️ | Vote | Vote on all the options together |
   | 3 | 🎉 | Go | Top pick wins. Plans made. |

   - Title font: Montserrat Bold, **24pt**
   - Description font: Montserrat Regular, **18pt**
   - Title color: `#7c3aed`

5. **QR Code (y: 6.8–8.5 inches, centered):**
   - QR size: **2 inches × 2 inches**
   - Position: horizontally centered
   - Generate QR pointing to: `https://togetherplans.app`
   - Use Canva's built-in QR code generator (Elements → QR Code) or paste exported QR PNG
   - Border: White rectangle 2.4in × 2.4in behind QR for contrast
   - Caption below QR (Montserrat Regular, 14pt): `Scan to download free`
   - URL text below (Montserrat Bold, 16pt, `#7c3aed`): `togetherplans.app`

6. **Footer strip (bottom 0.75 inches):**
   - Background: `#5b21b6`
   - Text: `Free for couples & groups  ·  @togetherplans`
   - Font: Montserrat Regular, **14pt**, white
   - Centered

**Print note:** For dark background version, download as PDF Print. For coffee shop/bulletin board, export 11×17 version at 2× proportional scaling. Laminate if outdoors.

## Template 5: Facebook / LinkedIn Cover — 1640×924px

> Doubles as a brand cover photo for both platforms. LinkedIn Company Page and Facebook Page share similar optimal dimensions.

### Canvas Setup
- Size: **1640 × 924 px**
- Note: Facebook displays at 820×312 on desktop; keep key content in center 820px×312px safe zone (y: 306–618px)
- LinkedIn displays at 1128×191 cropped from center; keep critical text in center strip

### Layout:

1. **Background:**
   - Linear gradient: left `#3b0764` → center `#7c3aed` → right `#5b21b6`
   - Canva: Background → Gradient → Linear, set to horizontal

2. **Decorative elements:**
   - Large semi-transparent circle: 700×700px, fill `rgba(255,255,255,0.05)`, positioned x: 1200px, y: -100px (right bleed-off)
   - Small circle: 200×200px, fill `rgba(255,255,255,0.07)`, x: 80px, y: 650px (bottom-left)
   - Dot pattern cluster: 3–5 small dots (8px each, `rgba(255,255,255,0.2)`) scattered top-left and bottom-right

3. **Calendar icon (left side decoration, x: 100–280px, y: 280–500px):**
   - Use Canva Elements → search "calendar" → pick clean minimal icon
   - Size: 180×180px
   - Color: white, opacity 20%
   - This is a subtle watermark, not a focal point

4. **Main wordmark (centered in safe zone):**
   - Text: `DateNight`
   - Font: Montserrat ExtraBold, **110px**, white
   - Position: centered horizontally, y: ~380px
   - Letter spacing: -1px

5. **Tagline (below wordmark):**
   - Text: `Plan Together. Go Together.`
   - Font: Montserrat Light, **44px**, `#ddd6fe`
   - Position: centered, y: ~500px
   - Letter spacing: 1px

6. **Subtle divider:**
   - Horizontal line: 400px wide, `rgba(255,255,255,0.2)`, 1px height
   - Position: centered, y: ~555px

7. **URL (bottom of safe zone):**
   - Text: `togetherplans.app`
   - Font: Montserrat Regular, **30px**, `rgba(255,255,255,0.65)`
   - Position: centered, y: ~590px

8. **Pink accent dot:**
   - Small circle: 10×10px, fill `#FF4081`
   - Position: just left of the "D" in "DateNight" (decorative brand mark)

**LinkedIn note:** The company banner crops heavily on mobile. Duplicate this design at 1128×191px as a separate "LinkedIn banner only" variant, keeping only the wordmark and tagline in large text.
