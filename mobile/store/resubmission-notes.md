## Notes for the Reviewer

Thank you for the review. Version 1.2.0 is a substantial rework of the app since the 1.0 submission: the discovery engine now returns live local event data (with photos, dates, ratings, and ticket links) across 15 categories, and the voting flow has been rebuilt around a new guest-voting feature.

**About the guest-vote link feature:**
Any proposal member can generate a share link (datemeup.app/vote/…). The recipient opens it in a browser and taps a favorite option — no account or download required. Guest votes are advisory only: they appear in the tally but never trigger the group's final decision, which requires votes from actual group members.

**About After Dark (17+ rating context):**
After Dark is an optional, opt-in late-night mode for couples, active only during evening hours. It is the reason for the 17+ age rating. It does not appear in any store screenshot and is not surfaced to users who don't seek it out.

**To see the core loop quickly:**
1. Log in with the demo account.
2. Open "Review Crew" → "Weekend plans" and vote on an option.
3. Tap "Invite someone to vote" to see the guest link flow.
4. Visit the Discover tab to browse live local events (location permission optional — defaults work).
